# Dobby Controller v1

Landscape Android Bluetooth RC controller for Dobby.

- UP `F`, DOWN `B`, LEFT `L`, RIGHT `R`
- Release sends `S`
- AUX1 `A1`, AUX2 `A2`
- PWM sends `V0`..`V100`
- Classic Bluetooth SPP
- Editable/resizable persistent controls

The APK is built by the GitHub Actions workflow in `.github/workflows/build-dobby-controller.yml`.
